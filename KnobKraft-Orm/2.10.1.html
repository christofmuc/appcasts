Features:

  • #426 Python adaptations can now wait for a synth to acknowledge uploads. Bank sends advance only after each patch is accepted, while device errors, timeouts and cancellations stop the transfer instead of continuing blindly. The Kawai K5000 uses this to recognize Write Complete and report write protection, full memory, missing expansion memory and other write failures. This is covered by simulated MIDI and C++ integration tests, but still needs confirmation on real K5000 hardware. Thanks to @markusschloesser for clarifying the K5000 write-acknowledgement protocol!

Bug fixes:

  • #573 Long bank downloads such as the Korg X3 no longer time out after ten seconds while partial SysEx data is still arriving. Thanks to @rolfoosting for the clear regression report! Automated timeout regressions pass; a hardware retest is still welcome.
  • #574 Behringer UB-Xa edit-buffer and bank downloads now recognize the broadcast FDS transfer followed by the device-addressed universal end message seen in the hardware trace. Thanks to @figman2 for the report and MIDI log! The parser and simulated transfers are covered, but the reported native crash was not present in the capture and should still be retested on the synth.
  • #559 and #570 Malformed Clavia Nord Lead MIDI files with embedded status bytes are now rejected instead of silently returning only the earlier valid patches. The setup documentation also clarifies that live memory-card banks depend on the model and installed card. The adaptation remains alpha and this hardening was not tested on hardware.
